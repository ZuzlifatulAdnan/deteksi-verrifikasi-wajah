Panduan Integrasi

Dokumentasi lengkap untuk mengintegrasikan FaceVerify API ke aplikasi Anda — mulai setup MySQL, semua endpoint, contoh kode, hingga tips produksi.

ℹ️
Server berjalan di port 8080. Semua endpoint diawali /api. Endpoint admin memerlukan header X-Admin-Key.

Langkah Instalasi

  1. Clone repo dan masuk ke direktori project.

  2. Buat virtual environment dan install dependensi:

PowerShell / Bash 
# Buat virtual environment
python -m venv venv
venv\Scripts\activate          # Windows
# source venv/bin/activate      # Linux/Mac

# Install semua dependensi
pip install -r requirements.txt

  1. Buat database MySQL dan user (atau biarkan server membuatnya otomatis):

MySQL Shell 
-- Jalankan sebagai root MySQL
CREATE DATABASE IF NOT EXISTS faceverify
  CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

CREATE USER IF NOT EXISTS 'fvuser'@'localhost'
  IDENTIFIED BY 'password_kuat_di_sini';

GRANT ALL PRIVILEGES ON faceverify.* TO 'fvuser'@'localhost';
FLUSH PRIVILEGES;
✅
Tabel users, logs, dan attendance dibuat otomatis saat server pertama kali dijalankan — tidak perlu jalankan migration manual.

  1. Salin .env.example ke .env dan isi nilainya (lihat bagian berikut).

  2. Jalankan server:

PowerShell / Bash 
python run.py

Server aktif di http://localhost:8080. Cek status: GET /api/health.

Konfigurasi .env

Salin .env.example ke .env lalu isi semua nilai berikut:

.env 
# ── MySQL (WAJIB) ──────────────────────────────────────
MYSQL_HOST=localhost
MYSQL_PORT=3306
MYSQL_USER=fvuser
MYSQL_PASSWORD=password_kuat_di_sini
MYSQL_DATABASE=faceverify

# ── Admin Secret (WAJIB) ───────────────────────────────
# Generate: python -c "import secrets; print(secrets.token_hex(32))"
ADMIN_SECRET=isi_dengan_string_acak_panjang_minimal_32_karakter

# ── CORS (sesuaikan dengan domain frontend Anda) ───────
CORS_ORIGINS=http://localhost:3000,https://app.domain.com

# ── Supabase (OPSIONAL — sinkronisasi cloud) ───────────
SUPABASE_URL=https://xxxx.supabase.co
SUPABASE_KEY=your-service-role-key

# ── Server ─────────────────────────────────────────────
HOST=0.0.0.0
PORT=8080

Endpoint: Register Wajah

POST /api/register Publik

Daftarkan wajah baru atau perbarui data wajah yang sudah ada. Gunakan multipart/form-data.

Parameter Form

FieldTipeWajibKeterangan
user_idstring✅ID unik (NIP, email, UUID, dsb.)
namestring✅Nama lengkap
emailstring—Email (opsional)
phonestring—No. HP (opsional)
imagefileSalah satuFile gambar (JPG/PNG)
image_base64stringSalah satuGambar dalam format base64 atau data URI
skip_spoofbool—false (default). Jangan aktifkan di produksi.

Respons Sukses (200)

{
  "success": true,
  "message": "Wajah berhasil didaftarkan",
  "user_id": "EMP001",
  "name": "Budi Santoso",
  "face_info": { "bbox": [120, 80, 340, 310], "det_score": 0.98 },
  "antispoof": { "score": 0.72, "passed": true }
}

Endpoint: Verifikasi 1:1

POST /api/verify Publik

Bandingkan wajah yang dikirim dengan wajah yang sudah terdaftar berdasarkan user_id.

Parameter Form

FieldTipeWajibKeterangan
user_idstring✅ID user yang akan diverifikasi
image / image_base64file/string✅Foto wajah saat ini
frame2_base64string—Frame ke-2 untuk motion liveness (opsional tapi direkomendasikan)

Respons Sukses (200)

{
  "success": true,
  "verified": true,
  "user_id": "EMP001",
  "name": "Budi Santoso",
  "similarity_pct": 87.3,
  "similarity": 0.8731,
  "confidence": "TINGGI",
  "is_live": true,
  "is_live_passive": true,
  "is_live_motion": false,
  "verdict": "TERVERIFIKASI ✓",
  "antispoof": { "score": 0.69, "passed": true }
}
💡
verified: true hanya jika similarity ≥ 0.30 DAN is_live = true. Selalu cek field verified, bukan similarity_pct saja.

Sistem presensi berbasis identifikasi wajah 1:N — tidak perlu input user_id. Terminal kiosk cukup kirim foto wajah.

Parameter Form

  "user_id": "EMP001", "name": "Budi Santoso",
  "similarity_pct": 86.2, "confidence": "TINGGI",
  "waktu": "2026-11-21 08:03:17",
  "message": "✅ Selamat datang, Budi Santoso! Presensi masuk tercatat."

POST /api/presensi/keluar Publik

Clock-out: identifikasi wajah dan catat presensi keluar. Parameter sama dengan /masuk.

GET /api/presensi/hari-ini Publik

Daftar presensi hari ini beserta statistik (jumlah masuk, keluar, total karyawan).

GET /api/presensi/riwayat/{user_id} Publik

Riwayat presensi satu karyawan. Query param: ?limit=30 (default 30).

GET /api/presensi/laporan Publik

Laporan range tanggal. Query param: ?dari=2026-11-01&sampai=2026-11-30&limit=200

Endpoint: Admin (Protected)

🔒
Semua endpoint admin wajib menyertakan header:
X-Admin-Key: <nilai ADMIN_SECRET dari .env>
Tanpa header ini server mengembalikan 401 Unauthorized.
POST /api/admin/verify-key Admin Key

Verifikasi apakah X-Admin-Key valid. Dipakai dashboard admin saat login.

// Respons jika valid:
{ "success": true }
// Respons jika salah:
{ "detail": "Key tidak valid" }  // HTTP 401
GET /api/users Admin Key

Daftar semua pengguna aktif (tanpa embedding).

DELETE /api/users/{user_id} Admin Key

Soft-delete pengguna (set is_active = 0, data tidak benar-benar terhapus).

GET /api/logs Admin Key

Log aktivitas terbaru. Query param: ?limit=50.

Contoh: JavaScript (Fetch API)

Register dari kamera browser

JavaScript 
// Ambil frame dari <video> → canvas → base64
function captureBase64(videoEl) {
  const canvas = document.createElement('canvas');
  canvas.width  = videoEl.videoWidth;
  canvas.height = videoEl.videoHeight;
  canvas.getContext('2d').drawImage(videoEl, 0, 0);
  return canvas.toDataURL('image/jpeg', 0.9);
}

async function registerFace(userId, name, videoEl) {
  const body = new FormData();
  body.append('user_id',      userId);
  body.append('name',         name);
  body.append('image_base64', captureBase64(videoEl));

  const res  = await fetch('/api/register', { method: 'POST', body });
  const data = await res.json();
  if (!data.success) throw new Error(data.error);
  return data;
}

Verifikasi dengan dua frame (liveness)

JavaScript 
async function verifyFace(userId, frame1, frame2) {
  const body = new FormData();
  body.append('user_id',       userId);
  body.append('image_base64',  frame1);
  body.append('frame2_base64', frame2);

  const res  = await fetch('/api/verify', { method: 'POST', body });
  const data = await res.json();
  return data.verified;   // true / false
}

// Panggil presensi masuk dari terminal kiosk
async function clockIn(imageBase64) {
  const body = new FormData();
  body.append('image_base64', imageBase64);
  body.append('device_id',    'TERMINAL-01');
  body.append('location',     'Kantor Pusat');

  const res  = await fetch('/api/presensi/masuk', { method: 'POST', body });
  return res.json();
}

Contoh: Node.js / Express (Backend Proxy)

Gunakan form-data + node-fetch jika FaceVerify berjalan terpisah dari app utama Anda.

Node.js — install: npm i form-data node-fetch 
const FormData = require('form-data');
const fetch    = require('node-fetch');
const fs       = require('fs');

const FV_URL    = process.env.FACEVERIFY_URL || 'http://localhost:8080';
const ADMIN_KEY = process.env.ADMIN_SECRET;

// ── Register ──────────────────────────────────────────
async function register(userId, name, imagePath) {
  const form = new FormData();
  form.append('user_id', userId);
  form.append('name',    name);
  form.append('image',   fs.createReadStream(imagePath));

  const res = await fetch(`${FV_URL}/api/register`, {
    method:  'POST',
    body:    form,
    headers: form.getHeaders(),
  });
  return res.json();
}

// ── Ambil semua users (admin) ─────────────────────────
async function listUsers() {
  const res = await fetch(`${FV_URL}/api/users`, {
    headers: { 'X-Admin-Key': ADMIN_KEY },
  });
  if (res.status === 401) throw new Error('Admin key tidak valid');
  return res.json();
}

// ── Express route: proxy presensi masuk ───────────────
app.post('/presensi/masuk', upload.single('photo'), async (req, res) => {
  const form = new FormData();
  form.append('image',     req.file.buffer, { filename: 'photo.jpg' });
  form.append('device_id', req.body.device_id || '');
  form.append('location',  req.body.location  || '');

  const r    = await fetch(`${FV_URL}/api/presensi/masuk`, {
    method: 'POST', body: form, headers: form.getHeaders(),
  });
  const data = await r.json();
  res.json(data);
});

Contoh: PHP (cURL)

PHP 
<?php
define('FV_URL',    'http://localhost:8080');
define('ADMIN_KEY', getenv('ADMIN_SECRET'));

// ── Helper kirim multipart/form-data ──────────────────
function fv_post(string $endpoint, array $fields,
                  array $headers = []): array {
  $ch = curl_init(FV_URL . $endpoint);
  curl_setopt_array($ch, [
    CURLOPT_POST           => true,
    CURLOPT_POSTFIELDS     => $fields,
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_HTTPHEADER     => $headers,
  ]);
  $body = curl_exec($ch);
  curl_close($ch);
  return json_decode($body, true);
}

// ── Register wajah dari path file ─────────────────────
function fv_register(string $userId, string $name,
                       string $imagePath): array {
  return fv_post('/api/register', [
    'user_id' => $userId,
    'name'    => $name,
    'image'   => new CURLFile($imagePath),
  ]);
}

// ── Verifikasi wajah ──────────────────────────────────
function fv_verify(string $userId, string $imagePath): bool {
  $res = fv_post('/api/verify', [
    'user_id' => $userId,
    'image'   => new CURLFile($imagePath),
  ]);
  return $res['verified'] ?? false;
}

// ── Ambil log (admin) ─────────────────────────────────
function fv_logs(int $limit = 50): array {
  $ch = curl_init(FV_URL . '/api/logs?limit=' . $limit);
  curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_HTTPHEADER     => ['X-Admin-Key: ' . ADMIN_KEY],
  ]);
  $body = curl_exec($ch);
  curl_close($ch);
  return json_decode($body, true);
}

// ── Contoh penggunaan ─────────────────────────────────
$result = fv_register('EMP001', 'Budi Santoso', '/uploads/budi.jpg');
if ($result['success']) {
    echo "Terdaftar: " . $result['name'];
}

Tips Produksi

Kualitas gambar

  • Resolusi minimal 640×480. Optimal 1280×720.
  • Wajah mengisi minimal 20% lebar frame.
  • Pencahayaan merata, hindari backlight dan bayangan keras.
  • Untuk liveness motion, kirim frame2_base64 yang diambil ~300ms setelah image_base64.

Keamanan

  • Jangan pernah expose ADMIN_SECRET di frontend — selalu kirim dari server.
  • Gunakan HTTPS di produksi. Set CORS_ORIGINS secara eksplisit.
  • Endpoint /api/users, /api/logs, /api/users/{id} hanya untuk backend-to-backend.
  • Aktifkan firewall agar port 8080 tidak diakses langsung dari internet — letakkan di balik reverse proxy (Nginx/Caddy).

Performa

  • Model InsightFace dimuat sekali saat startup (~10 detik pertama). Request pertama lebih lambat.
  • Identifikasi 1:N mencari seluruh tabel — normal untuk <5.000 user. Di atasnya pertimbangkan caching embedding.
  • Connection pool MySQL default pool_size=5. Naikkan di database.py untuk traffic tinggi.

Contoh Nginx Reverse Proxy

nginx.conf 
server {
    listen 443 ssl;
    server_name faceverify.domain.com;

    location /api/ {
        proxy_pass         http://127.0.0.1:8080;
        proxy_set_header   Host $host;
        proxy_set_header   X-Real-IP $remote_addr;
        client_max_body_size 10M;  # untuk upload gambar
    }

    location / {
        proxy_pass http://127.0.0.1:8080;
    }
}
